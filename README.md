Учебная работа по ООП "Штучки-дрючки"

В программе реализованы: процентная скидка, фиксированная скидка, скидка «3 по цене 2», промокод, скидка постоянного клиента, бесплатная доставка и скидка на первый заказ.
Программа считает стоимость заказа, применяет подходящие скидки и показывает итоговую сумму.

models.py - основные классы товаров, клиента и заказа
context.py - данные для расчёта скидок
discounts.py - классы скидок 
factory.py - создаются скидки
config.py -  конфигурация скидок
engine.py - основной расчёт
demo.py - пример работы программы
test_engine.py - тесты

Для запуска программы: python demo.py
Для запуска тестов: pytest
