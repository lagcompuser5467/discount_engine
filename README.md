# Движок скидок (учебный проект)

Учебный проект на Python. Реализованы 7 типов скидок и расчёт стоимости заказа с пояснениями применённых скидок.

## Файлы
- `models.py` — модели товара, позиции корзины, клиента, заказа и результата.
- `context.py` — контекст одного расчёта и список применённых скидок.
- `discounts.py` — абстрактная скидка и отдельные классы скидок.
- `factory.py` — создание стратегии по конфигурации.
- `config.py` — Singleton, который хранит конфигурацию скидок, но не заказ.
- `engine.py` — общий алгоритм расчёта; конкретные классы скидок не выбирает.
- `demo.py` — пример расчёта.
- `test_engine.py` — автоматические тесты.

## Краткая схема классов

```text
Product -> CartItem -> Order -> DiscountContext
Customer -----------^

Discount (общий класс)
├── PercentDiscount
├── FixedDiscount
├── ThreeForTwoDiscount
├── PromoDiscount
├── LoyaltyDiscount
├── FirstOrderDiscount
└── FreeDeliveryDiscount

DiscountFactory -> создаёт объекты скидок по конфигурации
ConfigProvider -> Singleton, хранит список скидок
PricingEngine -> применяет стратегии через общий интерфейс Discount
PricingResult -> base_total, applied_discounts, final_total
```

## Реализованные скидки
1. Процентная.
2. Фиксированная (при достижении порога).
3. «3 по цене 2» (самые дешёвые единицы бесплатно в выбранной категории).
4. Промокод (процентный или фиксированный, активность и дата окончания).
5. Лояльность (5% по умолчанию, не более 30 календарных дней с последней покупки).
6. Бесплатная доставка (при сумме товаров строго больше порога).
7. Первый заказ (10% по умолчанию).

## Порядок расчёта
1. «3 по цене 2».
2. Обычная процентная скидка **или** процентный промокод (выбирается более выгодный, при равенстве промокод).
3. Лояльность и скидка первого заказа, в порядке конфигурации.
4. Фиксированные скидки и фиксированный промокод, в порядке конфигурации.
5. Бесплатная доставка.

Скидки на товары не уменьшают стоимость доставки. `base_total` включает сумму товаров и исходную стоимость доставки. Итог равен оставшейся стоимости товаров плюс доставка.


## Округление и ограничения
Все денежные операции округляются до копеек методом **half-to-even** (банковское округление), после вычисления каждой скидки. Сумма скидки ограничена текущей суммой товаров; итог не ниже нуля. Цены и доставка не могут быть отрицательными, количество должно быть целым и больше 0. Процент скидки ограничен 0–100. Промокод сравнивается с учётом регистра; дата окончания включительна. Будущая дата последней покупки не даёт скидку лояльности.
